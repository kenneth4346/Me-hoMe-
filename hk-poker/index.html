Command grammar 講法
  • No name = current actor (highlighted). Say a name anywhere to act for that player: 阿強 all in, 阿明 raise 兩百.
  • call / 跟 / 扣 = match the highest bet (any number said is ignored).
  • raise 50 / 加50 / 加注一百 = raise by N on top of the highest bet. raise到 200 / 加到200 / raise to 200 = raise to N.
  • bet 100 / 下注100 = put in N. check / 過 / pass. fold / 棄 / 唔跟.
  • all in / 全押 / 梭哈 / show hand = push whole stack.
  • 阿強 stack 1200 / 阿強 籌碼 千二 = set 阿強's stack (manual correction, undoable).
  • next / 下一條街 = next street. undo / 取消 = undo. 阿強 win / 阿強贏 = payout to 阿強.
  • Numbers: 10, 50, 十, 二十, 五十, 一百, 百五 (=150), 兩百, 兩百五, 一千, 千二 (=1200).

Buy-in 記錄

玩家底數買入 $籌碼輸贏
籌碼 = 手上籌碼 + 今手已落 Pot 嘅注。輸贏 = 籌碼 − 底數 × 每底。「+1 底」同 Rebuy 一樣會加籌碼；「−1 底」只係改正底數（唔會郁籌碼），撳錯可以用 Undo 還原。
